# Team Zero — IBM Z Datathon 2026

Real-time scam SMS checker: paste a message and an ML model running on IBM LinuxONE flags it as Safe, Suspicious or Scam with a confidence score.

## Dataset

[SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection) by Tiago A. Almeida and José María Gómez Hidalgo, UCI Machine Learning Repository. Licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Included unchanged in `data/`.
